# BBEdit

A clone of the BBEdit editor, built with Electron and React.

## Install

Clone the repo and install dependencies:

```bash
git clone https://github.com/zackemannen81/BBEdit.git
cd BBEdit
npm install
```

## Starting Development

Start the app in the `dev` environment:

```bash
npm run dev
```

## Packaging for Production

To package apps for the local platform:

```bash
npm run package
```
